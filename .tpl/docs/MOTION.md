# 原站动效清单与实现依据

参考公开预览：<https://jiro.build/preview/template/marketing-sales/ai-marketing-landing-page-kelo>。以实际渲染与公开组件参数为准，不将详情标签中的月/年付切换或评价当作原站已实现区块。

| 区域 | 原站触发与参数 | 实现 |
| --- | --- | --- |
| 导航 | 初始 y=-20/opacity=0，0.8s easeOut | Shell 中独立入场 |
| 标题、说明、CTA | y=16，0.6s，.1/.2/.3 错峰 | Hero，按规范调整中英文字号 |
| 原视频 | Hero 2 Video.mp4，0.6 倍速、静音、inline、循环 | 本地 MP4；隐藏/离视区暂停；失败显式日志与原生控件 |
| 数据面板 | 容器上移入场、卡片 hover y=-4 | 独立面板区块，手机单列适配 |
| 面板进度 | 60/25/10%，1s，1/1.2/1.4s 错峰 | 分段宽度动画 |
| 销售折线 | pathLength 0→1，2s；节点和提示随后出现 | 真实 SVG 路径绘制；周/月切换可操作 |
| 概览柱 | 高度增长 .8s，1.5+.1i 错峰 | 视区触发高度动画 |
| 回访条 | 宽度 45/36%，1s，2/2.2s | 独立进度动画 |
| 实时分析 | 24 柱，1.5s 无限反向，.05i 错峰；切换三项指标 | 固定波形替代原站随机渲染，防 hydration 差异，节奏保留 |
| 自动化行 | x=-20→0，.3/.4s 错峰 | 独立横向入场 |
| API 光标 | opacity 1→0，.8s 无限 | 独立光标动画 |
| 协作环与头像 | 双环 10/15s 反向旋转，头像 scale .8→1，.4+.1i | CSS 环与头像错峰 |
| 四阶段标签 | hover scale 1.02，当前图标 2s scale 1/1.1/1 | 可点击与方向键切换，手机横向滚动 |
| 阶段切换 | AnimatePresence wait，x=20→0→-20，.4s，曲线 .22/1/.36/1 | 每阶段保留独立内容和示意动画 |
| 阶段示意 | 玻璃块 y=0/-10/0，4s 无限；背景 hover scale1.1/3s | 独立浮动与图像缩放 |
| 四种示意 | 线索 .1s 错峰；草稿行 x=-5/.1s；节点 scale .8/.1s；洞察 y=10/.1s | PhaseMockup 分支区分实现 |
| 集成 | 逐卡入场，边框/底色悬停 | 静态八项网格，无横向跑马灯 |
| 成果 | 标题 y20，说明 x20，面板 y40/.8s/.3delay | 面板入场；三端按规范重排 |
| 价格 | y20/.6s，.15s 错峰；按钮 hover | 三档价格与原图企业卡，无月年切换 |
| FAQ | 高度/透明度 .4s，.23/1/.32/1；控件旋转 .3s | 单项展开和可访问关联 |

有意差异：字体、标题尺度、中文语义、玻璃主题、宿主品牌及市场入口依规范调整；原站无实际业务的按钮改为明确的演示路径；移除装饰箭头；FAQ 文案统一为营销并明确素材权利；不照搬不相关 Shopify 页脚文本。扩展内页为原创演示，非原站已有页面。

减少动态：全局 MotionConfig 与各循环 useReducedMotion；CSS 环/脉冲停用；视频暂停并显示手动控件。实际三端运行与时间状态证据仍须补验，代码存在不等于完整动效验收通过。
